## One content trick that will make these much stronger

Don't title the video:

> **“How to build an AI SDR with Claude Code”**

That's tutorial content.

Instead:

> **“I gave an AI the job of an SDR.”**

Then reveal the implementation **inside the video**.

Your structure becomes:

**Hook → surprising result → screen recording → architecture → failure → result → CTA**

For example:

> “I gave Claude Code 500 companies and told it to find 20 that are likely to buy our AI agents.”

Then show the agent actually working.

At the end:

> “I used Claude Code + a few tools to build this. Comment `SDR` and I'll share the workflow.”

That gives you **virality + education + authority + a lead magnet** in one piece.

The most important rule: **don't make Claude Code the product. Make the transformation the product.** Claude Code is the machine you use to create the transformation.
