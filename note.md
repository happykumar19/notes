# How to use Claude Code as your teacher

Instead of asking it to build everything, use it as an interactive mentor. For example:

- "Design the architecture for a URL shortener. Don't write code yet."
- "What happens when 10,000 users click the same shortened URL simultaneously?"
- "Where should Redis fit into this architecture?"
- "Generate the project structure only."
- "Let's implement the authentication layer first."
- "Review my architecture and point out weaknesses."
- "If this application grows to one million users, what should change?"
